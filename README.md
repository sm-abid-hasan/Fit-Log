# 🏋️‍♂️ FitLog

**FitLog** is a modern, responsive web application designed to help users discover exercises, build daily workout plans, and track their fitness journey with a seamless, interactive user interface. 

## ✨ 5 Key Features

1. Dynamic Workout Planning: Add up to 5 specific lifts or exercises to your daily "My Plan" dashboard to stay focused on today's goals.
2. **Save for Later:** Bookmark favorite workouts into a dedicated "Saved" tab for quick access in future sessions.
3. **Real-Time Progress Tracking:** Mark exercises as "Done" with instant visual feedback and seamlessly manage completed tasks.
4. **Interactive Notifications:** Beautiful, custom-positioned toast notifications provide immediate confirmation for user actions like adding, saving, or completing workouts.
5. **Optimized User Experience:** Features custom loading animations, graceful 404 error handling, and robust local storage caching to preserve user data across sessions without relying on a backend database.

## 💻 Technologies Used

* Framework: Next.js (App Router)
* Library: React
* Language: TypeScript
* Styling: Tailwind CSS
* Icons: Lucide React
* Notifications: React Hot Toast
